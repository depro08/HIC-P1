Feedback & Error Handling

Golden Rules 3 & 4: Informative Feedback and Simple Error Handling

  • This page of the application demonstrates two Golden Rules: Offer Informative Feedback and Offer Simple Error Handling.
  • Informative feedback means that users should receive clear information about what happens after they perform an action.
  • Simple error handling means that users should be told when an error occurs and how to correct it.
