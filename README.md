# HIC-Project 1

The application I created is to provide an interactive way for users to learn about the 8 Golden Rules of Interface Design. Each page focuses on one or more of the Golden Rules through explanations and examples.

## Files

- `index.html`
- `dashboard.html`
- `shortcuts.html`
- `feedback.html`
- `closure.html`
- `reversal.html`
- `control.html`
- `memory.html`
- `script.js`
- `style.css`

## Instructions to Run The Application

1. Download or copy the files into the same VSCode folder.
2. Once you have all the files copied/downloaded, install the Live Server extension by Ritwick Dey in VSCode.
3. Open `index.html` in VSCode.
4. In the bottom right you should see "Go Live". Click that and it will open an external web browser to the project.
5. The welcome page will be displayed first. Click 'Next' to begin using the application.
6. Use the navigation menu at the top to also help move between the different pages.
7. Follow the instructions on each page to interact with the different examples.
