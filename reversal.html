Reversal

Golden Rule 6: Permit Easy Reversal Of Actions

  • This page demonstrates the Golden Rule: Permit Easy Reversal of Actions.
  • This means that users should be able to easily undo an action and return to the previous state.
  • The example below allows users to enlarge the text and then undo the change if they want to return to the original size.
