Golden Rule 8: Reduce Short Term Memory Load

  • This page demonstrates the Golden Rule: Reduce Short Term Memory Load.
  • This means that users should not have to process or remember too much information at one time.
  • The example below gives a simulation that divides an account setup form into smaller steps so users only need to focus on a few fields at a time.
