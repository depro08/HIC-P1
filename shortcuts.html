Golden Rule 2: Enable Frequent Users to Use Shortcuts

  • This page of the application demonstrates the Golden Rule: Enable Frequent Users to Use Shortcuts.
  • This means that experienced users should have faster ways to perform common actions.
  • The keyboard shortcuts below allow users to perform actions and navigate through the application more quickly.
