Golden Rule 1: Strive for Consistency

  • Use the navigation menu above to explore the eight Golden Rules of Interface Design.
  • This page of the application demonstrates the Golden Rule: Strive for Consistency.
  • This means that similar actions and interface elements should look and work the same way throughout an application.
  • To remain consistent throughout the application, each page contains the same navigation menu and a heading showing which Golden Rule the page describes.
